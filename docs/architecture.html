01Context & Goals

Problem

Tác giả tiểu thuyết cần công cụ hỗ trợ toàn hành trình sáng tác (ý tưởng → dàn ý → chương → kiểm tra). Tool hiện có (NovelCrafter, Sudowrite) giải từng mảnh, không có harness agent — agent tự chủ thao tác trên project tiểu thuyết qua tools + codex-as-context, giống Claude Code thao tác trên codebase.

💡 harness là gì?
Một "bộ khung" cho agent: vòng lặp + tools + context management + HITL. Agent chạy TRONG harness. Xem Glossary.

Goals (MVP "Harness-Proving Foundation")

IDGoalMô tả
G1Harness coreAgent (deepagents) chat-centric, HITL approval trước khi sửa manuscript
G2Codex structuredcharacters/timeline/lore trong Postgres — dual consumer: agent (@tools) + UI (rich views)
G3Manuscript = filesMarkdown trong StoreBackend, agent dùng built-in file tools
G4Runtime evalRubricMiddleware + 1-2 novel rubrics → agent tự self-eval & sửa mỗi turn
G5Offline evalMinimal suite (3-5 scenarios) → measure harness quality, regression check
G6Literary UIDesign "văn chương, bay lượn" — RIÊNG, phù hợp tác giả (không template/đại trà)
G7BYOK + HybridFree hosted + Pro + BYOK unlimited
G8MultilingualUI i18n + skill content đa ngữ

Non-goals (MVP)

  • P2: multi-tab subagents, timeline chart, skills library đầy đủ, cross-session memory
  • P3: collaboration, full pipeline automation, local-first
  • Skip: Ollama local full, full monetization tier matrix

03Data Model (ERD)

💡 Hybrid: 2 kiểu dữ liệu, 2 cách lưu
Bản thảo (prose) → markdown files (StoreBackend) — agent dùng file tools. Codex (structured) → Postgres tables — agent dùng custom @tools + UI render. Lý do: codex cần query + render portfolio/timeline; prose tự nhiên là text liền.

Codex (Postgres, RLS per user+novel)

novels
id · user_id · title · language · pov · tense
characters
id · novel_id · name · age · personality · arc · pov · color_theme · portfolio_data JSONB
locations
id · novel_id · name · description · geography
timeline_events
id · novel_id · title · date_label · sort_key · character_ids[]
lore
id · novel_id · category · title · body
items
id · novel_id · name · significance
relationships
id · novel_id · from_char · to_char · type
chapters
id · novel_id · number · title · status · word_count (metadata; prose trong StoreBackend)

Progressions (codex entry evolves per chapter — VD: Elena ch.1 bất tín → ch.8 tin) — stored trong portfolio_data JSONB hoặc bảng riêng character_progressions(character_id, chapter_id, state).

05ADRs

💡 ADR là gì?
Architecture Decision Record — hồ sơ ghi 1 quyết định kiến trúc: Bối cảnh → Lựa chọn → Quyết định → Hệ quả. Lưu lý do để tương lai không hỏi lại "tại sao không dùng X?".
ADR-001deepagents (Python) làm harness foundation
ContextCần harness engine không build from 0.
Optionsdeepagents.js (1.4k⭐ ít mature) · deepagents Python (25.8k⭐, có eval + RubricMiddleware) · Vercel AI SDK · build from 0
Decisiondeepagents Python.
Consequences+1 service Python BE; agent tools + domain co-located.
ADR-002Hybrid data model (manuscript files + codex structured)
ContextCodex cần render UI + query; manuscript là prose.
DecisionCodex = Postgres tables; Manuscript = markdown files (StoreBackend).
Consequences~10 custom @tools codex; built-in file tools manuscript.
ADR-003Next.js FE + Python FastAPI BE split (Option B)
ContextAgent tools + domain logic cùng language tránh duplication.
DecisionNext.js (UI/SSR) + Python FastAPI (mọi logic); Supabase (DB/Auth).
Consequences2 service; agent tools gọi domain service trực tiếp (0 hop).
ADR-004LangSmith Deployment cho agent runtime
ContextCần deploy agent + streaming + tracing + eval hosting.
DecisionLangSmith Deployment (langgraph.json + langgraph deploy).
ConsequencesManaged; FE dùng useStream SSE custom chat UI.
ADR-005BYOK + Hybrid monetization
ContextTránh gánh token cost; freemium entry.
DecisionFree (hosted cap) + Pro sub + BYOK (unlimited, 0 cost). Premium features gate bởi sub bất kể AI source.
ConsequencesBYOK qua @wrap_model_call đọc runtime.context.model + api_key.
MVP providersGemini (langchain-google-genai) · DeepSeek (langchain-deepseek, dùng deepseek-chat V3, không deepseek-reasoner R1) · ZAI/Zhipu (openrouter:z-ai/glm-5.2).
ADR-006Eval-driven continuous improvement
ContextHarness phải "tốt dần" — đo được → cải thiện có chứng cứ.
Decision2 lớp eval: runtime (RubricMiddleware + novel rubrics) + offline (adapt deepagents-evals). First-class trong MVP.
ConsequencesLoop: eval → weak criteria → improve Lớp 2 → re-eval → tag version.
ADR-007Design Direction A · Raw Elegance (iA Writer lineage) — LOCKED
ContextUser muốn design RIÊNG, phù hợp tác giả. "Game-like" = CẢM HỨNG game có design riêng, KHÔNG clone. Research iA Writer / Bear / Ulysses → minimal + typography-first + focus mode + light/dark.
DecisionDirection A · Raw Elegance. Light: paper #fbfaf6 / ink #1a1a1a / vermilion #a93226. Dark: ink #1a1a1a / cream #e8e4dc / terracotta #c47a5a. Newsreader (serif) + Inter + JetBrains Mono. Motion: cursor blink, fade focus. 100% custom (no shadcn). Tailwind v4.
AlternativesB · Cozy Study (Bear, Lora, walnut) — casual. C · Ink & Moon (ink-wash, Cormorant, slate) — độc đáo nhưng risk. Xem design-exploration.html.
ConsequencesiA Writer pattern proven; Newsreader free; 1 accent = maintain đơn giản. Hi-fi: writing-hifi.html.
ADR-008Supabase Postgres + RLS multi-tenant
ContextMulti-tenant (user × novel) isolation.
DecisionRLS user_id = auth.uid(); StoreBackend namespace (user_id, "novels", novel_id, ...).
ConsequencesIsolation built-in; Supabase JWT verify trong Python BE.

06EARS AC

ubiquitous
AC-1 System SHALL expose agent interaction via chat UI with streaming SSE.
state
AC-2 When agent requests manuscript edit, system SHALL pause for user approval (HITL).
event
AC-3 When user sends chat message, agent SHALL access codex (tools), manuscript (file tools), memory, skills.
ubiquitous
AC-4 System SHALL store codex in structured Postgres tables with RLS.
state
AC-5 When agent updates codex entity, UI SHALL reflect within 2s.
ubiquitous
AC-6 System SHALL render character portfolio with per-character color theme.
unwanted
AC-7 System SHALL NOT store codex as unstructured markdown.
event
AC-8 When agent completes chapter turn, RubricMiddleware SHALL eval against chapter rubric.
state
AC-9 If rubric = needs_revision & iter < max, system SHALL inject feedback & resume.
ubiquitous
AC-10 Offline eval SHALL run ≥3 scenarios, report category_scores (prose, consistency, pacing, POV).
state
AC-11 When offline eval shows category_score drop >5% vs prior, CI SHALL block prod.
ubiquitous
AC-12 System SHALL support UI i18n (≥2 langs) + multilingual skills.
optional
AC-13 System MAY allow BYOK for unlimited usage.
ubiquitous
AC-14 System SHALL gate premium features by subscription regardless of AI source.

10Deployment

Environments

dev: next dev + langgraph dev + supabase start · staging: Vercel preview + LangSmith staging + Supabase staging · prod: Vercel + LangSmith + Supabase prod

CI/CD with eval gate

PR → lint + typecheck + unit + build
  ↓ merge main
deploy staging → run offline eval (3-5 scenarios, N=3 trials)
  ↓ regression check: no category_score drop > 5%
PASS → deploy prod + tag harness version
FAIL → block, notify, manual override required

📖Glossary

harness
Bộ khung agent: vòng lặp + tools + context management + HITL. Agent chạy trong harness.
agent
AI tự chủ: nhận yêu cầu → gọi tools → làm việc → trả kết quả. Khác chatbot (chỉ trả lời text).
deepagents
Bộ harness open-source của LangChain, inspired by Claude Code. Lớp 1 (consume).
LangGraph
Runtime (engine) chạy agent. deepagents chạy trên nó.
LangSmith
Dịch vụ deploy + giám sát agent (ở ngoài stack runtime).
codex
"Sổ tay thế giới" — dữ liệu cấu trúc về nhân vật/địa điểm/timeline/lore. (Mượn thuật ngữ NovelCrafter.)
manuscript
"Bản thảo" — văn xuôi các chương. Lưu như file.
HITL (Human-in-the-loop)
Agent xin người duyệt trước thao tác nhạy cảm (sửa bản thảo).
rubric
Tiêu chí chấm điểm — VD: "chương phải nhất quán POV, pacing đều". Agent tự chấm theo.
RubricMiddleware
Cơ chế deepagents: agent tự chấm tác phẩm theo rubric, chưa đạt thì tự sửa.
BYOK
Bring Your Own Key — user mang API key AI riêng.
StoreBackend
Cách deepagents lưu "file" trong DB (Postgres) thay vì ổ đĩa.
RLS
Row Level Security (Postgres) — mỗi dòng chỉ visible cho user sở hữu.
ADR
Architecture Decision Record — hồ sơ ghi 1 quyết định + lý do.
EARS AC
Cách viết yêu cầu kiểm chứng được (ubiquitous/state/event/unwanted/optional + SHALL).
skill (SKILL.md)
"Kỹ năng" agent tải khi cần — VD: catalog trope, kỹ thuật viết.
memory (AGENTS.md)
"Trí nhớ" luôn tải — VD: tóm tắt thế giới, sở thích tác giả.
progression
Codex entry tiến hóa theo chương — VD: Elena ch.1 bất tín → ch.8 tin.
Scene Beats
Gạch đầu dòng "gì xảy ra" trong scene. Cầu nối outline → prose.
Appearance Heatmap
View hiển thị nhân vật/địa điểm xuất hiện ở chương nào — phát hiện gap/inconsistency.
